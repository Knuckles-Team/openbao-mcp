# CONN-OPENBAO-MCP — Requirements

Governing specification: [spec.md](spec.md).

Each row identifies one connector behavior and its verification target.

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-OPENBAO-MCP-R001` | **Governed transport.** The connector must send every OpenBao request through the SDK governed HTTP client built from its resolved TLS profile in `openbao_mcp/api/api_client_base.py`. Caller chain: an MCP tool of `openbao_mcp/mcp/mcp_secrets.py` calls `Client` in `openbao_mcp/api/api_client_full.py`, which calls `ApiClientBase.request` (`openbao_mcp/api/api_client_base.py:46`); the session was built by `create_http_client` (`openbao_mcp/api/api_client_base.py:25`). Shape: `create_http_client` with the resolved TLS profile in `openbao_mcp/api/api_client_base.py`; `Client.Headers()` in `openbao_mcp/api/api_client_full.py` mutates the governed client headers. Proving test: `tests/test_governed_http.py::test_requests_go_through_governed_client_with_token`. | `tests/test_governed_http.py` must exercise token and basic auth, namespace headers, the `LIST` method, empty bodies, and error statuses through the real client with a mock transport. |
| `CONN-OPENBAO-MCP-R002` | **Adopt scion-sdk 0.10.0 import paths.** openbao-mcp must import only paths that exist in `scion-sdk` 0.10.0 and must raise its floor to that release. The release removes the pre-layer paths without an alias (`SCION-CENTRALIZED-CAPABILITIES-R046`). Stage: dependency and import adoption. Edits, by file: `openbao_mcp/api/api_client_base.py`: `create_http_client` to `build_http_client(options)`; `tests/test_governed_http.py`: `create_http_client` to `build_http_client(options)`. Raise the `pyproject.toml` requirement `scion-sdk[mcp]>=0.9.0` to `scion-sdk>=0.10.0,<0.11.0` with the same extras and regenerate `uv.lock`. A client built by the old factory keeps its options argument; `build_http_client(options, async_=True)` returns the async client. No wrapper, alias or fallback import stays. Caller chain: the connector entry point `openbao_mcp` -> its modules above -> the public `scion_sdk` modules. Shape: import edits in the files named, one `pyproject.toml` edit and one lock edit; the new test reuses `ast` from the standard library. Depends on: SCION-CENTRALIZED-CAPABILITIES-R046. | Test: `tests/test_scion_sdk_0_10_imports.py::test_every_scion_sdk_import_resolves_on_the_pinned_release` (L2) parses every Python file of `openbao_mcp` and `tests` and asserts each imported `scion_sdk` module resolves with `importlib.util.find_spec`. |
