## Summary

This plan states how `openbao-mcp` delivers the rows of `CONN-OPENBAO-MCP-DATA-PLATFORM-OPERATIONS`. The live caller is the `openbao-mcp` console script. The owner is the `openbao_mcp` package. The rows reuse the `scion-sdk` helpers and add no second authority. The plan changes no runtime code.

### Phase 1: Design

### Existing system and reuse

The operation joins the existing tool surface in `openbao_mcp/mcp/mcp_secrets.py`. It reuses the connector's client and auth.

### Architecture

One tool per API operation. Read-only. The connector returns typed data; medulla maps it.

### Interfaces and data model

A new MCP tool with a typed result. No migration.

### Live integration path

Client call, then the MCP tool in `openbao_mcp/mcp/mcp_secrets.py`, then the backend API.

### Quality and release gates

The repo's pre-commit gates and the focused test named in the row.

### Risks, alternatives, and decisions

A backend without the capability returns a typed unsupported result.
